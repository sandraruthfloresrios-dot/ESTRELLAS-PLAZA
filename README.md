# Estrellas Plaza: galería y sistema de trabajo separados

La raíz del sitio es la galería pública, con el diseño del marketplace elegido. Contiene 66 registros del padrón más una ficha audiovisual pendiente de ubicación y marca. Los nombres comerciales siguen por confirmar. Incluye 105 piezas visuales conceptuales; los flyers de marcas ficticias no se asignan por índice a los negocios reales. Las propuestas del catálogo se identifican como muestras, sin pedidos ni cobros comerciales.

`gestion/` contiene exclusivamente la aplicación interna: acceso autorizado, fichas privadas, tareas/editores, calendario, rodajes, briefs, archivos de equipo y pauta. No es una página de presentación ni contiene los documentos del antiguo sitio. El frontend anónimo no contiene registros de trabajo, nombres de responsables ni el presupuesto del equipo. La URL y clave Publishable de Supabase son públicas por diseño. El acceso a los datos y archivos requiere autenticación y membresía; la base utiliza RLS, funciones con comprobación de permisos y control de versiones para evitar sobrescrituras entre sesiones.

La activación del esquema privado y de la cuenta propietaria se prepara en un instalador SQL privado, fuera de este repositorio público. No está aplicada desde el entorno de desarrollo: su red bloquea Supabase. Las pruebas locales y con mocks no prueban el proyecto remoto. No se deben añadir SQL de inicialización, respuestas de briefs, nombres de responsables, credenciales, secretos ni datos operativos a los archivos estáticos.
